# UI/UX Spec

Pantallas:

1. Captura teléfono/email.
2. Selección de canal.
3. Enviando código.
4. Fallback en proceso.
5. Capturar dato faltante para canal alterno.
6. Ingreso OTP.
7. Éxito.
8. Error/bloqueo.

Mensaje para fallback sin target:

```text
No pudimos enviar el código por el canal principal y necesitamos un dato adicional para intentar otro canal.
```
